# chatgpt-local

## Identifier

`chatgpt-local`

## Display Name

ChatGPT (local)

## Description

Local conversations from ChatGPT Work, Codex desktop, or Codex CLI. Cloud-based ChatGPT conversations are outside this tool definition.

## Source Location

`~/.codex/sessions`.

## Source Items

`rollout-*.jsonl` and `rollout-*.jsonl.zst`, including files in subdirectories.

## UID

The `payload.id` of the `session_meta` record.
