# Note

- What It Is: the owner's words, given in the ingest prompt either as text after `Owner note:` or as the absolute path of a Markdown file after `Owner note file:`; see Owner Notes in `SCHEMA.md`.
- Capture: the text verbatim as Markdown, or for a file, a byte-for-byte copy of it.
- Original Location: none.
- Identity: none.
- Version: none.
- Ignore: none.
- Author: all of it is the owner's.
- Anchor: none.
- Updated At: capture time.
- Dir: `notes`.
