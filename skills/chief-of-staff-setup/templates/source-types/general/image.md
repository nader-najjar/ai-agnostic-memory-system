# Image

- What It Is: an absolute path to a PNG, JPEG, GIF or WebP file the guardian can view; for an image pasted into a chat, the copy the AI tool itself saved.
- Capture: a byte-for-byte copy.
- Original Location: the absolute path the image was read from.
- Identity: none.
- Version: none.
- Ignore: none.
- Author: none.
- Anchor: none.
- Updated At: the file's modification time.
- Dir: `images`.
