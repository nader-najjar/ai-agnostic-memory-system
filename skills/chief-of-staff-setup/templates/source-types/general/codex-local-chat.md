# Codex Local Chat

- What It Is: a local Codex thread's rollout file, the session log the Codex engine writes for the Codex CLI, the Codex IDE extension and ChatGPT's Codex work mode: `<codex home>/sessions/<yyyy>/<mm>/<dd>/rollout-<time>-<thread id>.jsonl`, or the same name under `<codex home>/archived_sessions/`, where `<codex home>` is `$CODEX_HOME` or else `~/.codex`. A cold file may be compressed to the same name plus `.zst`, and a reverted thread's file adds `_<rollout id>` after the thread ID. It is confirmed as the intended thread by a distinctive recent owner message. Not a thread whose first line's `session_meta` payload has a `source` of `subagent` or `internal`, or a `thread_source` that is present and other than `user`: those are Codex's own sub-agents, reviews, guardian checks and memory jobs. Not a Codex cloud task, and not a regular ChatGPT chat.
- Capture: a byte-for-byte copy of the file as found, `.jsonl` or `.jsonl.zst`. A compressed capture is read with `zstd -dc`.
- Original Location: the file's absolute path.
- Identity: the thread ID, the `id` in the first line's `session_meta` payload.
- Version: the SHA-256 of the decompressed rollout lines, so compressing a cold file does not make a new version.
- Ignore: every line except `event_msg` lines carrying the conversation, which are `user_message` and `agent_message` payloads in a thread whose `session_meta` `history_mode` is `legacy` or missing, and `item_completed` payloads whose `item.type` is `UserMessage` or `AgentMessage` in a `paginated` thread. Everything else is the engine's own record: `session_meta`, `turn_context`, `compacted` summaries, token and state records, inter-agent messages, and `response_item` lines, the model-facing copies that also hold `AGENTS.md`, environment context, developer instructions, reasoning and tool calls and output. Also ignore IDE context the extension puts before the owner's words: when a message starts with `# Context from my IDE setup:`, only the text after `## My request for Codex:` is the owner's.
- Author: the `message` of each `user_message` payload, and the `text` parts of each `UserMessage` item's `content`, are what the owner typed. Image and audio parts and `images`, `local_images` and `local_audio` paths are the owner's attachments, not their words. Pasted or quoted text is not the owner's unless the owner says they wrote it. Every other line is not the owner's.
- Anchor: the line number in the decompressed rollout.
- Updated At: the `timestamp` of the last line.
- Dir: `chats`.
