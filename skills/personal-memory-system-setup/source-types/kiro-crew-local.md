# kiro-crew-local

## Identifier

`kiro-crew-local`

## Display Name

Kiro Crew (local)

## Description

Conversations from the Kiro Crew dashboard.

## Default Source Location

`~/.kiro/crew/sessions`.

## Source Items

`dashboard_chat-*.jsonl` directly in the selected location.

## UID

The session identifier between `dashboard_chat-` and `.jsonl` in the source filename.
